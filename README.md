# 保研自荐信写作 · Outreach Letter

让个人经历与导师研究形成具体联系，写清楚为什么申请、为什么联系这位老师。

[下载 Skill](baoyan-outreach-letter.zip) · [查看完整规则](baoyan-outreach-letter/SKILL.md) · [查看硕士参考模板](baoyan-outreach-letter/references/masters-letter-template.md)

## 这是什么

写自荐信时，个人经历可以列出一大段，到了导师研究部分，却只剩“方向契合”“非常感兴趣”。

读过导师主页，也找到了论文，仍不知道该选哪个连接点、保留哪些经历，才能把联系理由讲具体。

这个 Skill 从你的真实材料出发，先理清写信主线，再围绕选定导师组织内容，完成中文保研自荐信、套磁信或首次联系邮件。

支持硕士、直博、跨方向申请，以及已有信件的修改。

> 用具体经历支撑申请，用具体研究说明联系理由。

## 表达示例

以下为虚构示例，假设学生参与过问卷设计、数据清洗和分时段统计，导师公开研究涉及校园公共空间使用。

**泛泛表达**

> 我对您的研究方向非常感兴趣，也具备一定的数据分析能力，希望加入您的团队学习。

**形成具体联系后**

> 了解到您关于校园公共空间使用的研究后，我希望进一步学习如何从行为数据中理解空间需求。本科期间，我曾参与食堂排队调查，承担数据清洗与分时段统计工作。这段经历让我开始关注，不同时间段的活动差异可以怎样帮助理解空间使用，也希望在读研阶段继续学习相关研究方法。

具体成稿会根据导师证据、个人经历和本人真实兴趣调整。

下载并解压 [Skill 压缩包](baoyan-outreach-letter.zip)，保留完整目录，在支持 Skill 的 AI 助手中加载。


也可以让具备本地文件读取能力的 AI 先读取 `baoyan-outreach-letter/SKILL.md`。没有完整项目报告时，可以从课程、阅读、竞赛或实践经历开始。

## 会得到什么

- **详细自荐信**：保留相关经历的推进过程，说明个人训练、联系理由与学习意向。
- **首次联系邮件**：根据邮件用途精选内容，提供主题与正文。
- **指定范围的修改稿**：按需要调整导师段、研究经历、申请目的或其他部分。

默认交付本次需要的一封信或指定段落。需要 Word 文件时，可提出排版要求，文件导出与预览按当前环境的可用工具完成。

## 写信怎样进行

1. **读取已有材料。** 复用简历、完整项目整理、导师报告或旧信。
2. **明确本次申请。** 起草完整信件前，明确硕士或直博及本次联系对象。
3. **展示写信主线。** 说明准备突出什么经历、连接哪项研究、提出什么请求。
4. **补齐关键缺口。** 只追问影响本封信的个人事实、理解和意愿。
5. **起草并核对。** 检查贡献、结果条件、论文依据、申请类型和附件安排。

查找导师资料、组织经历和提出连接思路由助手承担；你主要补充只有自己知道的信息。

## 核心特点

- **承接已有成果**：完整项目整理与导师筛选报告可以直接使用。
- **围绕一条主线**：精选最能支撑本次申请的经历与研究连接。
- **导师段有依据**：使用论文时优先核对源 PDF，并阅读相关正文。
- **阅读表述符合实际**：助手读过与学生本人读过分别记录。
- **申请目的统一**：硕士、直博的动机、规划与结尾请求对应本次真实意向。
- **篇幅适合用途**：详细材料保留过程，首次邮件突出重点。
- **适应不同背景**：实验、文献、调查、设计、课程与实践均可提供写作依据。

信件内容以个人事实和实际证据为基础。发送邮件与联系导师由使用者安排。
