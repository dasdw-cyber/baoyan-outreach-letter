# 导师资料与匹配依据

这是由助手根据检索、阅读和对话逐步整理的工作资料，不要求学生先填完，也不随信附给导师。记录已核实的信息与实际阅读范围；未知项可留待确认，不通过题目猜测方法和结论。

## 对象与申请场景

- 老师姓名、学校或院所、学院或部门：
- 身份核实来源与查看日期：
- 相关研究方向及来源：
- 申请类型与学生当前联系阶段：
- 招生或活动信息（仅在需要写入信件时核实，记录适用年份与来源；未知即未知）：

## 筛选报告衔接（已有报告时填写）

- 报告位置、核查日期及选定导师对应章节：
- 使用者本次选择联系该导师的依据（本人说明或上下文，不以推荐排序代替）：
- 报告已有的联系依据、匹配性质与差异：
- 报告已选论文、材料位置与助手实际阅读范围：
- 报告中的未知项、阶段结果或待核实标记：
- 本封信需要复核的当前信息与拟用原文、复核结果及来源位置：
- 相对报告作出的必要调整及原因（无则省略）：

## 拟引用的研究（仅保留与本次写信有关的条目）

- 论文、著作章节或项目名称：
- 作者、发表年份、发表载体或版本等可核实信息：
- 老师与该成果的作者关系及依据：
- 源论文 PDF 路径：
- 其他正文来源及位置（论文优先源 PDF；著作章节等按实际载体记录）：
- 实际可读取范围（相关正文／仅摘要／题目／项目或官网介绍）：
- 已阅读的页码或章节：
- 核心问题：
- 与学生相关的关键方法或结果及原文位置：
- 不能由现有材料支持的表述：
- 学生本人是否阅读、阅读到何种程度（以学生确认的信息为准）：

## 本次匹配判断

- 学生真实经历中的对应事实及来源：
- 最有依据的一个连接点：
- 联系属于共同问题、方法迁移还是初步兴趣：
- 研究对象、尺度、方法或基础上的重要差异：
- 学生需要补足且愿意学习的内容：
- 可以写入信件的表述及证据边界：
- 影响成稿的待确认问题（如无则省略）：

## 连接记录（按需填写）

| 学生事实及位置 | 导师研究事实及原文位置 | 可支持的联系 | 差异或待补基础 |
| --- | --- | --- | --- |
| 只记录本次最相关的连接 | | | |

该表是后台分析，不要求学生先填，也不作为信件正文。公开信息、助手提出的连接与学生真实认识分别记录。
