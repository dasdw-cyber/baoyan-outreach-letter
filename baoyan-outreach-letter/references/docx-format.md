# Word 段落格式

仅在用户要求生成或调整 `.docx` 时使用。以下保留原工作流的排版偏好，作为新建中文自荐信正文的默认值。用户明确要求或指定模板优先；仅修改文字时保留已有排版。

## 正文默认值

| 项目 | 设置 |
| --- | --- |
| 对齐、方向、大纲级别 | 左对齐、从左向右、正文文本 |
| 文本之前与之后缩进 | 0 字符 |
| 特殊缩进 | 首行缩进 2 字符 |
| 段前与段后 | 0 行 |
| 行距 | 1.5 倍行距 |

使用段落属性设置首行缩进，不用手工空格代替。称呼、标题与落款按其独立用途排版，不机械套用正文首行缩进。

## 换行、分页与网格

启用：孤行控制、按中文习惯控制首尾字符、允许西文在单词中间换行、允许标点溢出边界、自动调整中文与西文间距、自动调整中文与数字间距。

关闭：与下段同页、段中不分页、段前分页、允许行首标点压缩。

保留“如果定义了文档网格，则自动调整左缩进”和“如果定义了文档网格，则与网格对齐”。不为套用该选项额外创建文档网格。

字体、字号和纸张没有来自本 skill 的固定要求，优先沿用用户模板；新文档选择一致、常规且可读的设置即可。

## 文件检查

保存后检查文件可读取、正文完整、姓名与落款正确，以及实际段落属性是否生效。具备预览条件时查看换页、段落密度和长英文题目的显示；只能检查结构时如实说明未进行视觉检查，不把仅保存成功视为全部排版已验证。
