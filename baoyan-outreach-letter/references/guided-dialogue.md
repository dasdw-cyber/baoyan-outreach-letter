# 材料优先的自荐信引导

先帮助用户看清“这封信可以怎样写”，再补充只有用户知道的关键事实。默认一轮一个核心问题；STAR与证据检查由助手后台完成，不让用户先证明创新性或自行分析导师匹配。

## 入口：先读已有材料

新会话没有材料信息时，首问：

> 你手头有没有可以直接读取的材料，比如完整项目整理、导师筛选报告、简历或旧自荐信？有就从材料开始，没有也可以直接聊。

用户回答有，再问相关文件或文件夹位置并直接读取；已有路径、附件或正文就跳过已知问题。位置不可访问或内容不可读时，说明实际范围，提供当前可行的粘贴或附件方式，也可继续口述，不假装已经读取。

文件夹包含多位学生或多个旧版本时，先辨认本次对象和相关材料，不混合成绩、设备、指标与报名状态。不把老师旧信中的研究方向当作其他老师的匹配依据。

## 先提取，不重新采访

| 已有输入 | 助手先做什么 |
| --- | --- |
| 导师筛选报告和完整项目整理 | 先读取筛选依据与导师总览，明确本次收件人，再读取该导师分析、配套论文和对应项目，提出写信主线 |
| 完整项目整理和简历 | 完整整理提供方法、贡献与结果条件，简历提供身份、成绩、项目名、角色和时间；只补本次申请缺口 |
| 只有简历 | 提取已有行动与结果，先形成可用经历思路；缺少关键条件时再问，不默认要求写完整项目报告 |
| 只有旧自荐信 | 明确改稿范围，复用可确认的个人事实，重新检查收件人、研究证据与当前阶段 |
| 没有文件 | 接受一句口述的经历与申请想法，先整理暂定主线，再小步补问 |
| 只提供了目标老师 | 先确认对象不歧义，查找官网与相关研究；再了解已有个人材料，不能凭老师方向生成学生经历 |

同一会话已经用项目整理 skill 形成过完整报告时，直接复用，不让用户重新描述背景、方法、结果。细节有冲突只澄清相关点，不按文件名裁决。

“没有项目”不等于没有可写材料。已有课程论文、阅读笔记、调查、作品或实践记录时，按本学科的真实活动读取和提炼；只有简历与课程基础也可以开始。已有足够内容时不要求补出科研项目、量化指标或发表经历，具体取舍见 [写作方法](writing-guide.md)。

## 承接导师筛选报告

`baoyan-supervisor-match` 默认交付一份《学校全称导师筛选报告》，配套 PDF 可位于报告旁的“论文/导师姓名/”目录。按实际链接定位文件；相对路径以报告所在目录为基准，不假定当前工作目录或固定盘符。链接失效时先在已提供材料范围内查找或按论文原始页面获取，仍不可读就说明缺口，不要求用户重做报告。

| 报告中的部分 | 本次写信如何使用 |
| --- | --- |
| 筛选依据与范围 | 读取明确意向或候选方向、项目材料位置、核查日期和资料限制；区分本人意愿与助手建议 |
| 导师比较总览 | 辨认候选姓名、现任单位与主页；未选择时辅助定位收件人，不重排推荐顺序 |
| 逐位导师与相关论文分析 | 读取选定导师的研究问题、具体联系、差异、论文及解读、招生未知项和“后续联系的研究依据” |
| 选择建议与后续衔接 | 复用选文、建议阅读重点和未解决事项；建议关注某人不等于用户已经决定联系 |

同等内容可在正文、其他格式或旧版报告中，按内容识别，不要求使用者改成固定标题。用户已选定老师时聚焦其相关部分，无需重读所有候选的论文；尚未选择时先简短概括已有候选区别，再只问“这次想给报告中的哪位老师写信？”。即使报告只列一位，也不能在用户未选择时默认替其决定。选定老师不在报告中时，仅补查该老师所需资料。

将报告的联系依据与完整项目整理中的具体贡献、行动、结果条件对应。报告中的项目摘要用于定位，不能取代已有完整版；完整材料暂不可用时可使用报告中有明确来源的事实，不补造省略的细节。用户更新了研究意愿或项目事实时，调整本封信的主线与必要连接，不因旧报告排序否定新意愿，也不自动重启全校筛选。

报告若标为阶段结果、待核实候选或仅基于摘要，继续保留该边界；针对本封信缺少的依据补查，或按已核实的官网方向表达。论文原文和当前信息的复核按 [论文匹配规则](paper-matching.md) 执行。报告不作为学生已读论文、已取得推免资格或愿意提前进组的证明。

## 明确收件人与本次意图

姓名、学校和单位已知时，复用已有身份依据并按需核实当前信息；有报告但未选择时按上一节确定对象，没有报告且对象不清时再问学校与姓名，不要求用户一次填写导师履历、论文清单和所有招生信息。

申请类型是起草完整信件的必需信息。本次尚未明确时，读取材料后先只问：“这次准备申请硕士还是直博？”用户已明确时直接沿用；旧材料里“以后希望读博”不等于本次申请直博，文件夹同时有两种版本也不能自行选择。用户尚未决定时可解释两种申请在本封信中的动机与请求差别，继续整理已有事实，待其选择后成文。用户明确只要通用结构模板时可保留类型占位符；局部修改不涉及申请类型时遵守原修改范围。

当前联系阶段与希望得到的回应按缺口逐步确认，已经说清就复用，不把入营等同于取得推免资格。只有希望了解方向而没有目标老师时，可以先整理个人经历与方向兴趣，不虚构定向信，也不自动开始全国导师筛选。

用户没有材料时，可以请其随意说目前想申请什么方向，记得的经历也可以一起讲。先接住已有内容，不立刻抛出成绩、创新、技术原理和长期规划问题。

## 先给写信主线

已有基本个人材料和导师信息后，先作一个短的整理，例如：

> 你目前最具体的积累是……；老师公开研究中的……与你的……可以连接。信里可以先交代申请目的，再用这段经历说明已有训练，随后写具体联系与希望学习的内容，结尾提出……。

每一项都有相应依据；暂未核实的导师研究、个人兴趣和连接关系标明待了解或暂定。不把缺少关系的项目强行串成统一主线，也不因为双方都用某个算法就认定高度契合。

如果只有零散经历，先整理“做了什么—有哪些阶段—得到什么结果”的暂定链，未知处保留。用户补充后只更新变化部分，不每轮重复全部提纲。

主线初步清楚后再定位个人贡献，初期允许用户用“我们”讲整体，不频繁打断。已有项目材料清楚时不退回深入采访。

## 再选一处关键缺口

| 当前真正缺口 | 适合的下一问 |
| --- | --- |
| 报告中有候选但本次对象未定 | “这次想给报告中的哪位老师写信？” |
| 申请类型不清，准备起草完整信件 | 必须先问“这次准备申请硕士还是直博？”，得到答案后再组织完整信件 |
| 收件人有歧义 | “这位老师是哪所学校或哪个学院的？” |
| 个人参与范围不清 | “这几项工作中，你主要承担哪一部分？” |
| 结果条件缺失且需要引用 | “这个结果对应模拟测试还是实际观测？” |
| 个人兴趣尚不明确 | “这两个有依据的连接中，哪一个更接近你想继续学习的内容？都不合适也可以。” |
| 报名阶段影响表述 | “你目前准备报名、已经报名，还是已进入该项目？” |
| 文字用途确实不清 | “这次需要详细自荐材料，还是首次联系的邮件正文？” |
| 拟写个人阅读体会但本人阅读情况未知 | “这篇论文你自己读到了哪部分？还没读也可以，我会按实际情况措辞。” |

不是所有缺口都要问。可省略的成绩、无关项目和可选规划无需阻碍起草。用户已经给答案时不照表追问；没有具体结果也可使用已完成产物与实际训练，不凑数字。

## 导师研究由助手先读、先解释

根据 [论文匹配规则](paper-matching.md) 优先读取报告已选的相关论文并核对拟用内容；缺少依据时再补查，不让学生重选或先总结论文。学生尚未读过或看不懂时，先解释一个相关问题与方法，指出原文位置及与其经历可能的联系，再邀请表达理解或困惑；不代替其宣称精读。本人阅读情况未知但信件可用客观了解表述时，不把读完论文设为起草前提。

连接分析由助手提出。已有训练与目标方向不同等情境，先说明共通的问题意识、材料处理或方法训练与实际差异，再整理可写的学习目标，不让学生为了配合建议认领没有掌握的能力。

## 何时成稿

通常需要明确申请人与收件人、本人本次选择的硕士或直博申请意图、一项可用的经历或真实兴趣依据，以及对应的导师方向信息。无需人人都有论文、科研指标或逐年计划。申请类型未定时不因其他材料充分就跳过确认。

能写得准确且有内容就成稿。缺失可选信息就省略，关键事实不清时明确为待补草稿；用户只改一句时遵循其范围。个人项目整理不是本 skill 的额外交付前提。

信中不出现材料状态、检查表、来源索引或内部推理。待补项和必要解释单列；用于邮件时给主题与正文，用于详细材料时给完整正文。后续只更新变化，不重新从首问开始。

## 虚构使用片段

以下项目、导师和单位为教学情境，不是实际事实资料。

**用户：** 我想给筛选报告中的示例大学陈老师写自荐信。简历、完整项目整理和报告都在刚才提供的文件夹中。

助手直接读取材料，沿报告链接查找陈老师的论文，不重复询问文件位置或联系对象。

读取后，假定完整项目整理明确记载用户完成传感数据采集课程项目，负责数据整理和测试，并表示希望继续学习数据质量评估；报告已选一篇陈老师参与发表的论文，已核实的摘要涉及连续观测中的数据质量。助手尝试获取正文仍未成功，学生阅读情况未知，申请类型尚未提供。

**助手：** 可以沿用报告中陈老师的联系依据，以你的数据整理和测试训练，连接老师对连续观测数据质量的关注，再说明希望继续学习质量评估。目前论文只核实到摘要，信中会按这一范围表达，结尾可以询问招生和交流机会。这封信主要申请硕士还是直博？

**用户：** 硕士。

**助手：** 我会按硕士申请来组织，把课程项目准确写成已有训练，结尾询问招生和交流机会。没有确认的入营状态与提前进组安排先不写入。

此时其余基本信息若已齐全即可起草，不再要求用户填创新点、发表目标或三年计划。
