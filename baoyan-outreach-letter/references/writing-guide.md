# 写作方法与示例

需要组织学习与实践积累、处理经历较少或跨方向申请、选择信件篇幅时读取。以下为虚构教学片段，只展示写法；不得把示例中的经历、能力、兴趣或导师信息当作用户事实。

## 先决定这个学生有什么值得写

从已读材料中选出与本次联系有关、且本人实际承担或理解最清楚的内容。相关性、证据与个人参与程度比经历名称更重要；不默认科研优于课程、竞赛优于实习，也不机械地把所有奖项和项目排进正文。

| 主要积累 | 可以写清的具体内容 |
| --- | --- |
| 实验、计算或工程研究 | 问题、个人工作、方法选择、验证条件与阶段结果 |
| 文献、史料、理论或文本研究 | 关注的问题、材料选择、比较或论证过程、本人形成且有依据的认识及其范围 |
| 调查、案例或社会实践 | 调查对象与范围、本人承担的收集整理或分析、观察与解释的区别；未做因果检验就不写成因果结论 |
| 设计、创作或专业实践 | 任务与约束、本人方案或作品、修改依据与实际完成状态；未实施或未评价的效果不写成已实现 |
| 主要是课程与阅读基础 | 与目标相关的学习内容、确实完成的练习或读写积累、真实问题与希望继续学习的方向 |

这些是可选的叙述重点，不是经历分类问卷。一位学生可同时拥有几类积累，只取本封信需要的部分；没有完整项目时也可用扎实的学习基础和具体兴趣组织简洁的自荐信。只有笼统的“喜欢这个方向”且没有任何具体依据时，再小步了解相关课程、阅读或一次真实接触，不替其编出兴趣起源。

## 从项目整理进入自荐信

优先读取完整项目整理中的问题、本人任务、方法选择、结果与条件；简历用于定位项目名、角色、时间和相关基础。已写清的内容不重复采访，缺少与本次导师连接有关的信息才补问。

从项目中选择最相关的一条行动线，保留“为什么做—本人怎样推进—结果或判断有什么依据”的逻辑，写成自然段。简历的四字或五字加粗标签不直接搬入自荐信，完整报告的所有参数和过程也不必全部展开。项目之间没有实际联系时不强串成持续多年的研究路线。

详细自荐材料可将一段较完整的经历分为几个相连的自然段：先交代实际问题与本人任务，再说明已有做法、关键选择或调整，最后说明验证与阶段认识。有真实联系的前后经历可以写清前一阶段如何支持后一阶段；只有一项短经历时就写一项，不凑阶段。每段保留推进关系，不把简历要点换成逗号串联，也不把完整项目报告原样贴入。

先给一段写信思路，让用户知道会突出什么；技术、个人分工和验证口径等只在已有材料不足且需要引用时继续澄清，不要求用户先提交创新点总结。

## 经历段：从真实任务中形成说服力

从“问题—职责—关键选择—阶段结果—认识”中选择有材料支撑的内容。通常最需要补问的是本人具体做了什么、为何这样做、怎样知道工作有效。无需为了结构完整虚构困难或结果。

假设材料明确记载：学生负责课程中的环境数据采集原型，完成采集程序；发现异常值后加入记录检查；只完成室内测试，没有长期部署数据；本人表示由此关注数据质量并希望继续学习相关处理方法。可写：

> 在环境数据采集课程项目中，我主要负责采集程序编写和数据整理。测试中出现异常记录后，我增加了数据检查步骤，并结合原始日志排查采集过程中的问题。目前，原型已完成室内测试，长期连续运行的稳定性仍需进一步验证。这段训练让我开始关注观测条件和数据质量如何影响后续分析，也希望继续学习传感数据处理与可靠性评估。

这里的价值在于职责、具体行动和进展边界。不能把它扩写为“主持科研项目”“实现长期稳定运行”或添加没有提供的精度提升。

已有研究结果时，保留支撑判断的条件。例如材料只提供模拟数据上的表现，就明确为模拟验证；用户尚未做实测验证时，不写“已在真实场景中验证”。

不依赖实验或数字的经历也应具体。例如材料已确认：学生在历史学课程论文中比较两份地方志对同一事件的记述，负责版本与出处核对，论文尚未发表；本人希望继续学习史料辨析。可写：

> 在历史学课程论文中，我比较了两份地方志对同一事件的记述，主要完成版本与出处核对，并整理其中的差异。由于材料范围有限，我将讨论限定在这两份文本之内。这项训练也使我希望进一步学习史料辨析与文本比较的方法。

此例体现材料处理与论证边界，不能扩写为发现新史实、推翻既有结论或已发表研究。两个经历示例中的兴趣与感受均须有本人确认，不能仅凭做过相应工作自动添加。

## 导师段：选一个有依据的连接点

证据范围、阅读措辞与原文记录遵循 [导师研究与论文匹配](paper-matching.md)。本节只说明表达组织，不替代原文核对。

可以按以下功能组织，不要求逐句照抄：

1. 指出关注老师哪项研究中的什么问题。
2. 用原文支持的具体问题、论证思路或方法说明理解。
3. 连接学生经历中的一个事实或困惑。
4. 说明受到的启发或希望学习的内容。

只有“都用了机器学习”“都重视创新”之类联系时，继续寻找具体问题、观测方式、验证方法或理论上的联系；找不到就诚实写初步兴趣。

假设已核实的论文使用物理模型生成模拟数据，学生本人做过另一研究对象的模拟数据建模，但没有目标领域训练；本人确认关注模拟条件与真实观测的差异，希望学习验证方法。可写成：

> 我了解到您在相关参数估计研究中，利用物理模型构建模拟样本，再结合观测数据检验模型的适用性。这让我联想到自己在课程研究中使用模拟数据开展建模的经历，尤其关注模拟条件与真实数据之间的差异。我的前期训练涉及不同的研究对象，仍需要补足这一领域的理论与观测基础，也希望进一步学习如何更合理地设计验证过程。

使用时必须替换为真实研究名称、方法、本人经历和阅读范围。“已经精读”需要学生本人确认，不能因为 AI 读到了正文就代替学生宣称。

只有官网信息时，写清公开方向与自身兴趣即可：

> 从学院主页了解到，您的研究关注城市公共空间与居民活动。我的课程设计曾涉及社区空间使用情况的整理，由此对空间设计如何回应居民需求产生了兴趣，也希望在研究生阶段进一步学习相关调查与分析方法。

此例不包含论文、实证发现或导师评价。实际生成时，两侧事实都应有相应材料支持。

## 常见情境的组织方式

| 情境 | 内容安排 |
| --- | --- |
| 有较完整科研经历 | 精选与老师有关的项目，写清本人贡献、方法选择和阶段结果 |
| 只有课程、竞赛或实习 | 保留真实经历类型，通过具体任务体现学习能力和问题意识 |
| 暂无相关实践 | 从已确认的课程与阅读说明兴趣来源，提出具体学习方向，不制造项目 |
| 跨方向申请 | 先确认差异，再解释可迁移训练和待补基础 |
| 初次联系 | 尽早说明身份、申请目的和最重要依据；末尾提出明确请求 |
| 已报名或已入营 | 按真实状态说明联系背景与交流诉求，不重复写准备报名 |
| 已有交流或转介绍 | 简洁说明真实联系背景，不扩大他人的推荐或承诺 |
| 申请直博 | 说明真实的长期研究动机及已有训练，不只是替换硕士版的阶段标题 |

## 篇幅、规划与措辞

邮件正文优先保障主要信息可快速理解；详细自荐材料可展开关键研究过程。没有统一适用于所有人的字数要求。用户有明确字数或格式时服从其要求。

完整自荐信可参考“申请身份与动机—相关学习基础—导师研究连接—个人研究经历—客观基础与学习意向—联系请求”的功能顺序，按材料调整，不强制每项单独成段。段落之间围绕同一主线展开，避免重复叙述同一兴趣或成果。

沿用详细样本风格时，导师定制要贯穿所选经历、学习意向与联系请求。前文已经确定的具体连接，应能解释为何突出这段经历、希望补什么基础，以及本次向老师咨询什么；不能只在单独一段介绍论文，其他部分仍与目标无关。各处补充不同信息，不反复复制同一段匹配理由。

首次联系邮件尽早交代申请目的，保留一项最能说明训练的经历和一个具体连接，结尾给出明确请求。用户未要求时不同时生成完整信、短邮件和研究计划等多套稿件。

规划主要回答“希望继续研究什么、愿意从什么基础工作做起”。除非用户需要，不默认展开逐年计划、指定投稿期刊或承诺发表成果。硕士后的读博意愿和提前协助科研的安排，均来自本人实际意愿。

起草前先按 [对话引导](guided-dialogue.md) 明确本次申请硕士还是直博。两者使用同一份真实经历，但组织重点不同：

- **硕士申请**：说明已有基础、希望补足的知识与研究训练，结尾咨询相应硕士招生或交流机会；只有本人确认时才写硕士后继续读博的意愿。
- **直博申请**：根据本人实际认识说明为何希望接受持续研究训练、已有经历如何支撑这一选择，以及希望继续探究的问题，结尾咨询直博招生或交流机会。材料尚不足时只补问相关动机，不编造长期志向或独立研究能力。

两种类型都不套用固定培养年限或发表承诺。类型变化时同步检查开头、动机、规划与请求，不只替换几个名词。

原样本的长度、抒情程度、祝愿语和段落顺序不是通用标准。沿用本次用户明确的表达偏好；没有偏好时保持清楚、礼貌、具体，避免让不同学生都使用相同的感悟与结尾。个人风格不降低事实与证据要求。

可用“受到启发”“希望进一步学习”等表达，但让后面的具体内容承担说服力。避免每段反复致歉、赞美或宣誓，也不靠贬低其他方法来表达欣赏。

结尾可以询问与本次申请有关的招生或交流机会。只提出当前需要解决的问题；用户未表示愿意或有空提前参与研究时，不自动加入这项承诺。

单次改稿只改用户要求的部分。发现事实冲突时另列待确认点；文风偏好不作为擅自扩大修改范围的理由。
